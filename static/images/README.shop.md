# Customer storefront image assets

Current retail revision uses only `product-image-unavailable.svg`: an original neutral image icon, with an explicit missing-image label in templates. Product has no image storage contract. No category, brand, name or ID is mapped to a pretend product image. The artwork below is retained for history; current customer templates do not reference it.

## Previous illustrations

Created for this project on 2026-10-12. All `shop-*.svg` files in this directory are original SVG artwork authored for the customer storefront. They are local assets and require no remote image service, CDN, or font.

- `shop-court.svg`: abstract badminton court, racket and shuttlecock banner.
- `shop-racket.svg`, `shop-shoes.svg`, `shop-shuttle.svg`, `shop-bag.svg`, `shop-apparel.svg`, `shop-accessory.svg`: generic illustrations of product types.
- `shop-generic.svg`: fallback illustration when the product type has no matching illustration.

These illustrations do not depict an exact brand, product model, colour variant, or included accessory. Show them with an explicit illustration label; do not present them as photographs of the listed product. Product names, prices and brands continue to come from the database. No image field or image-to-model mapping is implied by these assets.

Storefront layout references consulted:

- [VNB Sports homepage](https://shopvnb.com/): search, account navigation, category navigation and product sections.
- [VNB racket listing](https://shopvnb.com/vot-cau-long.html): price filters and product information hierarchy.
- [FBShop homepage](https://fbshop.vn/): product sections separated by category.
- [FBShop racket listing](https://fbshop.vn/vot-cau-long/): filter controls and product detail links.

These pages informed layout research only. No logos, photographs, illustrations, product images, interface code or brand identity were copied or downloaded from them.
